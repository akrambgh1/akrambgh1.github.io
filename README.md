# 👨‍💻 Developer Portfolio

My personal portfolio site, showing nine projects I built with live demos and source code.

**🔗 Live:** https://akrambgh1.github.io/

Built with **plain HTML, CSS and JavaScript**: no framework, no build step, fast and easy to edit.

## ✨ Features

- Hero with GitHub avatar, an "Open to work" badge and quick stats
- **Featured projects** with large previews and highlights
- **All projects** grid with filters (Frontend, Full-stack, AI)
- Live **GitHub data** (last update, stars), loaded from the GitHub API
- Skills, About and Contact sections
- 🌙 **Dark / light mode** (follows the system, remembers your choice)
- Scroll-reveal animations (turned off when "reduce motion" is on)
- Responsive, accessible (skip link, focus styles, semantic HTML), with SEO / Open Graph tags

## ✏️ Customize

Everything is in **`data.js`**: name, role, bio, links, skills and the project list. Change it and push, and GitHub Pages updates the site automatically.
